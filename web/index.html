Method

How this works

Everything here comes from the scores posted on LeagueApps. A model turns those scores into a rating for each team. The ratings give every remaining game a chance of a win, a draw or a loss, and the dashboard plays out the rest of the season 25,000 times with those chances. Points that teams have already won stay put; only the games still to come are simulated.

Ratings

A team's power rating is how many goals per game it would beat an average team by, plus 5. So 5.0 is an average team, 6.0 is a goal a game better, and 4.0 is a goal a game worse. Ratings adjust for opponents, so a narrow loss to the best team can count for more than a win over the worst.

The 80% range under each rating is where the team's true level probably sits. Teams with few games have wide ranges. When two teams' ranges overlap a lot, treat them as roughly equal, whatever their ranks say.

There are three ways to build the ratings, and you can switch between them at the top of the page.

Game odds

For a single game, the gap between two ratings is the expected goal margin. Real games are noisy, so the forecast treats the final margin as uncertain around that number, with the amount of noise based on how often games in this league end level. Rounded to whole goals, a positive margin is a win, zero is a draw, and a negative margin is a loss. Dixon-Coles works a little differently: it estimates how many goals each team will score and adds up the chances of every possible scoreline.

There is no home advantage, since every game is played on the same field.

The rest of the season

Each simulated season starts from the real standings and plays every remaining scheduled game using the odds above. Teams are then ranked by points, goal difference and fewest goals conceded, the order LeagueApps uses. Because real points carry over, a team with a modest rating but several wins in the bank can still have good playoff odds.

The top four make the playoffs. First plays fourth, second plays third, and the two winners meet in the final. A drawn playoff game is treated as a coin toss.

Clinched and eliminated tags look at points alone and assume every tie on points goes against the team, because goal difference can't be known in advance. They are exact once 10 or fewer games are left, and cautious before then.

The schedule isn't a full round robin: every team misses one opponent. Projections play only the real fixtures. The Full round robin switch on the Standings race tab adds the missing games, so you can see how much the skipped matchups matter.

How accurate is it?

To test the forecasts fairly, every past game is predicted again using only the results from before it was played, as if the dashboard had been run that week. Each prediction gets a log loss score, which measures how surprised the forecast was by what actually happened. The table shows the average per game; lower is better. The coin-flip row is the bar to clear. It ignores who is playing, splits the win chances evenly, and uses this season's draw rate so far, starting from 17% until enough games are in.

The weekly recap on the Matches tab uses the same before-the-game forecasts. An upset is a win by the underdog. A draw counts as half a win for each side, so it is never an upset, even though any particular draw is unlikely.

Fine print

The September 3 forfeit counts in the standings but not in any rating.

Margins are capped so one blowout can't take over: at 4 goals for goal margin and 2 for results + margin, and Dixon-Coles ignores a team's goals past four in a game. One big win can still move a team with few games a long way, so check its range and its games on the Teams tab.

Consistency, on the Teams tab, is the typical gap in goals between a team's results and what today's ratings expect. It judges every past game with today's ratings, so it is a hindsight measure.

Forecasts use each team's best-guess rating and don't widen for how unsure that rating is.

On the Result graph, each arrow points from the winner to the loser, and thicker arrows mean bigger wins. When teams beat each other in a loop (A beat B, B beat C, C beat A), the graph groups them, because there is no clean order among them. Dominance flow is a résumé score: each team starts with one credit, keeps 40% and passes 60% to the teams that beat it, with more going to bigger wins. It is switched off while any loop exists.
